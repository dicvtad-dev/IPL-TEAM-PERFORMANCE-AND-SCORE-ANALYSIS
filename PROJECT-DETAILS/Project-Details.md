# IPL Cricket Data Analysis

## 1. Project Information

- **Project Name:** IPL Cricket Data Analysis
- **Author:** Divyesh Tadvi
- **Tool:** Microsoft Power BI
- **Domain:** Sports Analytics
- **Training:** On-the-Job Training (OJT)

## 2. Project Objective

The objective of this project was to analyze IPL cricket data using Microsoft Power BI and develop an interactive report to understand team performance, individual match outcomes, and batting and bowling statistics.

The project involved working with multiple datasets, preparing the data for analysis, creating relationships between tables, and developing visualizations to present cricket-related insights.

## 3. Dataset Information

The project uses five datasets:

| Dataset | Purpose |
|---|---|
| Matches | Contains match details, participating teams, winners, and match results. |
| Deliveries | Contains ball-by-ball information, including batting and bowling details. |
| Team Description | Provides information about IPL teams. |
| Players Information | Contains individual player details. |
| Match Dates | Provides date-related information for matches. |
